# Is the causal link dropped by the AV, or never worth carrying?

The readout keeps both endpoints of an influence and loses whether one caused the other. Whether that is the verbaliser failing to say it, or the objective never paying for it, decides whether the gap is fixable. If reconstruction is the objective, a fact the objective values should raise reconstruction when stated.

| arm | centred cos | sem |
|---|---|---|
| baseline | +0.1391 | 0.0207 |
| +true link | +0.1441 | 0.0200 |
| +false link | +0.1424 | 0.0201 |
| +neutral | +0.1599 | 0.0175 |

true − false = **+0.0017** (p=0.598); true − neutral = **-0.0158** (p=0.000515); true − baseline = +0.0050 (p=0.259).

**Verdict:** STRUCTURAL. Stating the link truly is worth no more to the reconstructor than stating it falsely (+0.0017, p=0.6), so nothing in the reconstruction objective ever paid for carrying it. The readout omits the cause because the training signal is indifferent to it, and prompting the AV differently will not recover it.

> The false and neutral arms are what make this readable. Adding any sentence perturbs the text, so "+true beats baseline" alone proves nothing — the question is whether it beats the same sentence made wrong, and one that is irrelevant.

> Scoring is centred; Gemma's AR reads about 0.99 for any text uncentred and has no dynamic range left to show a difference.
